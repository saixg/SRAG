# Definition of Done

A task is complete only when all applicable conditions are satisfied.

## Implementation

- [ ] code exists
- [ ] ownership is clear
- [ ] interfaces are typed
- [ ] configuration is explicit
- [ ] errors are handled

## Testing

- [ ] unit tests
- [ ] integration tests where required
- [ ] security tests where required
- [ ] endpoint tests where required

## Security

- [ ] no authorization bypass
- [ ] no secret leakage
- [ ] tenant scope preserved
- [ ] RLS preserved where applicable
- [ ] model context contains only authorized evidence where applicable

## Documentation

- [ ] current state updated
- [ ] relevant contract updated
- [ ] architectural decision documented if needed

## Verification

- [ ] tests actually run
- [ ] failures investigated
- [ ] no unverified claims reported as complete

## Final report

The agent must state:

```text
Implemented
Files Changed
Tests
Security Verification
Known Limitations
Next Task
```
